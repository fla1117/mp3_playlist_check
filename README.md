# mp3_playlist_check

로컬 음원 라이브러리 기반 YouTube 음악 보유 여부 판별 및 플레이리스트 분석 도구입니다.  
**윈도우 데스크톱 네이티브 GUI** 및 **고성능 CLI**를 모두 제공합니다.

---

## 🖥️ 윈도우 데스크톱 GUI 실행

프로젝트 루트 폴더의 **`run_gui.bat`** 파일을 더블클릭하면 즉시 GUI가 실행됩니다.

```cmd
# 탐색기에서 run_gui.bat 더블클릭 또는 명령줄 실행:
run_gui.bat

# 또는 파이썬 직접 실행:
python -m src.gui
# 또는 CLI 스크립트 실행:
mp3-check-gui
```

### GUI 주요 탭 안내
1. **🔍 YouTube 보유 여부 판별**:
   - YouTube 일반 영상, YouTube Music, Shorts, 플레이리스트, 챕터 모음집 영상 URL 입력 후 원클릭 판별
   - 판별 배지(`✅ 보유`, `⚠️ 유사`, `❌ 미보유`), 종합/세부 일치율, 판별 사유 제공
   - 매칭된 로컬 음원 정보 표시, `[📂 탐색기에서 위치 열기]`, `[▶️ 기본 플레이어로 재생]`, `[📋 경로 복사]` 지원
   - 플레이리스트/챕터 영상 시 테이블 목록 및 필터(`보유만`, `유사만`, `미보유만`), 더블클릭 탐색기 열기 지원
   - **(신규 v0.3.0)** `[📋 미보유 곡 목록 복사]`: YouTube 모음집에서 누락된 미보유 곡 목록만 순번/제목/길이와 함께 클립보드에 원클릭 복사
   - **(신규 v0.3.0)** `[📥 결과 CSV 저장...]`: 전체 판별 결과(순번, 판별상태, 유튜브제목, 재생시간, 로컬매칭음원, 일치율, 파일경로, 사유)를 Excel 한글 깨짐이 완벽 방지된 UTF-8 with BOM(`utf-8-sig`) 형식으로 내보내기
2. **📁 음원 폴더 스캔 & 라이브러리**:
   - `[📂 폴더 찾아보기...]` 다이얼로그로 공백/한글 경로(`F:\2. 음악\Music\3차 편집`) 원클릭 선택 및 자동 저장(`settings.json`)
   - 백그라운드 멀티스레드 스캔(UI 멈춤 없음) 및 실시간 프로그레스 바 / 결과 요약 배너
   - 라이브러리 실시간 검색(아티스트, 곡명, 앨범 등), 더블클릭 탐색기 열기, 재생 지원
3. **📊 라이브러리 품질 감사 & 정밀 관리 (FR-10, v0.3.0 전면 강화)**:
   - 종합 통계 카드(활성 음원, 유실 음원, 포맷별 분포, 썸네일 상태, 오류 건수)
   - 4대 감사 카테고리 전환 및 개별 작업 지원:
     - **👯 동일 곡 중복 보유 목록**:
       - 카노니컬 아티스트 별칭 및 피처링(feat.) 분리 해소 기반 고도화된 Union-Find 클러스터링
       - 동일 중복 그룹별 지브라 줄무늬 교차 시각화(`#ffffff` / `#f1f5f9`) 및 체크박스(`☐`/`☑`) 선택
       - `[⚡ 저음질/하위 중복 자동 선택]`: 그룹 내 최고 품질 음원(커버아트 보유 > 고음질 비트레이트 > 파일크기 순)을 보존하고 나머지 하위 음원을 원클릭 자동 체크
       - `[🗑️ 선택 파일 삭제]`: 선택된 파일들을 디스크에서 영구 삭제하고 DB에서 즉시 제거
       - **안전 삭제 가드(Safety Guard)**: 중복 그룹 내의 모든 파일이 선택된 경우 삭제를 원천 차단하여 라이브러리 원본 유실 완벽 방지
     - **🖼️ 커버아트 누락 곡**:
       - `[🖼️ 선택 곡 커버아트 자동 채우기]`: 동일 앨범 음원의 커버아트 로컬 공유(1순위) 및 iTunes Search API 고해상도(600x600) 검색/내장(2순위)을 백그라운드 멀티스레드로 자동 수행
       - `[📁 내 PC 이미지로 커버 넣기...]`: 사용자 PC의 이미지 파일을 선택하여 다수의 선택 음원 파일에 일괄 임베딩
     - **🏷️ 메타데이터 결측/추론 곡**:
       - `[🏷️ 추론된 가수·제목을 실제 태그에 저장]`: 파일명/폴더명 기반 정규화 엔진이 추론한 메타데이터를 실제 파일의 ID3/Vorbis/MP4 태그에 영구 기록
       - `[✏️ 파일명을 '가수 - 제목' 형식으로 통일]`: 파일명을 `[가수] - [제목].[확장자]` 표준 규격으로 일괄 변경하고 DB 파일 경로 및 인덱스 실시간 갱신
     - **⚠️ 스캔 오류 파일 목록**:
       - 바이너리 손상 또는 파싱 불가능한 음원 목록 및 사유 확인, 원클릭 탐색기 열기
4. **👥 한/영 아티스트 별칭 사전**:
   - 등록된 별칭 목록 조회, 대표 아티스트-별칭 간편 등록(`[➕ 별칭 등록]`) 및 삭제(`[🗑️ 선택 별칭 삭제]`)

## 💻 CLI 사용법

어느 디렉토리에서 실행하든 절대 경로로 프로젝트 DB에 연결되며, 공백이 포함된 경로도 따옴표 유무에 관계없이 안전하게 스캔합니다.

```bash
# 로컬 음원 폴더 스캔 (따옴표 없이 공백 포함 경로 입력 가능)
mp3-check scan "F:\2. 음악\Music\3차 편집"
# 또는
python -m src.cli scan F:\2. 음악\Music\3차 편집

# YouTube URL 보유 여부 조회 (단일 / 플레이리스트 / 챕터 모음집)
mp3-check check "https://www.youtube.com/watch?v=..."

# 로컬 라이브러리 통계 및 품질 감사 리포트
mp3-check stats
mp3-check stats --missing-covers
mp3-check stats --missing-tags
mp3-check stats --duplicates

# 아티스트 별칭 조회 및 추가
mp3-check alias list
mp3-check alias add "아이유" "iu"
```

## ⚙️ 코어 엔지니어링 특징
- **절대 경로 고정**: `PROJECT_ROOT` 기반으로 어느 작업 디렉토리에서 실행하든 `data/music_library.db`와 `data/settings.json`에 일관되게 접근.
- **증분 스캔 최적화 (NFR-1)**: 트랙 맵 전체 사전 인메모리 로딩 및 `(mtime, file_size)` $O(1)$ 비교로 수만 곡 증분 동기화 3초 이내 완료.
- **파일 이동/이름변경 감지**: 파일 앞 64KB + 뒤 64KB + 파일크기 SHA256 `partial_hash`로 재파싱 없이 경로만 즉시 갱신.
- **안전한 삭제 감지**: `Path.is_relative_to`를 적용하여 `Pop` 폴더 스캔 시 인접 형제 폴더(`PopRock`) 오탐 방지.
- **N+1 SQL 해소**: 아티스트 별칭 인메모리 캐싱(`Repository._alias_cache`)을 통해 하이브리드 검색 시 $O(1)$ 즉시 매핑.
- **Mojibake 복구**: CP949 바이트가 Latin-1로 잘못 인코딩된 구형 MP3 태그 자동 복원.
- **커버 아트 무의존성 추출**: PNG/JPEG 바이너리 헤더 파싱을 통해 PIL 등 외부 의존성 없이 해상도 및 MIME 추출.
- **버전 변경 내역 관리**: 상세 릴리즈 히스토리는 [Change_log.md](file:///c:/Users/user/Desktop/Project/mp3_playlist_check/Change_log.md) 참조.
